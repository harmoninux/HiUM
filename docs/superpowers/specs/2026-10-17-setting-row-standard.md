# 设置项范式标准（2026-10-17 定稿）

配置/创建流程中一切「设置项行」的统一规范。组件实现在 `entry/src/main/ets/lib/uiWidgets.ets`，
token 在 `lib/uiTokens.ets`；视觉稿见同目录 `2026-10-17-setting-row-standard-mockup.html`。

## 大原则

> **标签和注释都在左侧（堆叠），具体操作项在右侧，垂直居中。**

「垂直居中」的锚点是**整块**（标签 + 注释），不是标签首行。右侧控件只对标签行居中、
注释吊在块底的形态已全数废弃——真机 dumpLayout 实测：chips 旧置底形相对整块偏上
~27px、开关同病，用户逐处打回（2026-10-17）。

推论：

- **desc 一律左堆叠**（标签下方，tSub + cWeak，超一行换行），无「置底整宽」形态；
- 开关/选项行左列弹性（layoutWeight(1)），控件列按内容宽贴右；
- 值型行（输入/只读/信息）保留 72vp 固定标签列——表单列对齐只在纯表单场景有意义，
  与 B 形行不共屏（名称在基础 Tab、GDB 在高级 Tab），无对齐冲突。

## 七范式

| 范式 | 布局 | 说明（desc） | 现役用例 |
|---|---|---|---|
| FieldRow | 72 列标签 + 输入框 32 | 不配（placeholder 给示例） | 名称 / 监听端口 / 内核参数(多行变体) |
| ValueRow | 72 列标签 + 纯文本值 | 无 | 架构 |
| ToggleRow | B 形：标签+desc 左堆叠、开关右居中 | 按判据 | 只读/磁盘接口外全部开关 |
| ChipRow | B 形：标签+desc 左堆叠、chips 右居中 | 按判据，可随选中联动 | 显卡 / 磁盘接口 / 网卡型号 / 分配方式 |
| ChipGroup | 组形态：wrap 流式 / 磁贴 / FoldHead 折叠 | 组级说明置组尾 | 架构卡 / 机器类型磁贴 / CPU 机型 |
| SliderRow | 标签左 + 滑条右固定宽 160 + 值最右 64 成列 | 不配（自解释连续量） | 核数 / 内存 / 容量 |
| InfoRow | 72 列标签 + 主值/sub(tMono) + 动作钮右居中 | 无 desc；sub 是数据非注释 | 系统盘 / 数据盘 |

要点：

- **TextInput 默认上下 padding 8vp**，32 高必须显式压到 sp1，否则文字被裁（历史实测）；
- **Toggle 不可 .height() 压**（图形随盒缩放）；组件盒下沿自带 ~14px 留白，可见开关
  相对文字视觉偏上 ~7px ≈ 2.4vp，统一 `.translate({ y: 2.4 })` 补偿（含列表行内裸 Toggle）；
- **InfoRow.mainDim**：空态占位（未配置）降为 tSub + cWeak——占位与真数据同档会抢视线；
- 成员禁名 `enabled`（CustomComponent 基类占用），置灰位叫 `enable`。

## desc 判据制

满足其一才配，自解释项不配（复述 label 的一律删，如「声音」）：

1. 术语望文不生义（RNG / Balloon）；
2. 选择有隐性代价（virtio vs IDE 的 Windows 驱动问题）；
3. 行为反直觉；
4. 默认值需背书（RTC 本地时钟）。

## 合法特例（不违背大原则，逐条有案）

- **内核参数多行输入**：多行控件顶对齐（垂直居中会让标签悬在半空）——多行控件行规；
- **向导组形态**（架构选择卡 / 机器类型磁贴 / CPU 机型折叠流式）：>4 选项的结构化
  选择组，非行式设置项；
- **光盘 ISO 块**（VmEdit 存储 Tab）：标签 / 文件名（通栏，移除落行尾最右）/ 动作钮
  一行两个，整块上下堆叠——挂载态在单行里放不下三个动作（移除/选择文件/内置），
  左右两列形会让移除吊在文件名与右列之间（真机打回）；
- **VmStorage 动作条 / 列表行**：数据左 + 操作钮右居中，本身符合大原则。

## 已废弃形态（勿回退）

| 废弃形 | 原因 |
|---|---|
| desc 置底整宽（chips/开关） | 控件只对标签行居中，相对整块偏上 ~27px |
| ToggleRow.descBelow 逃生口 | 同病；desc 统一左堆叠换行 |
| Slider 全宽置底 | 唯一「操作项在行外」的范式 |
| 光盘行「无」占位 / 文件名（启动盘）后缀 / 内置 Alpine(arch) 后缀 | 冗余（用户定，2026-10-17） |
| PortForwardEditor「暂无规则」空态文案 | 冗余 |

## 改动与验收

- 改 UI 后必跑 `make ui-check`（未豁免的内容宽行扫描；有意居中/贴右的行标
  `// ui-layout-ok: 理由`）；
- 垂直居中与否用真机 `uitest dumpLayout` 量测文字块与控件的 bounds 中心差，
  截图（`snapshot_display`）辅助看观感；
- 组件级改动两页（VmEdit / VmWizard）同看，避免单页修好另一页回退。
