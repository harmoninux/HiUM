钮旁读数 chip（常显）+ 点开监控卡（线程榜）· 2026-10-16 · 静态评审用，vp:px ≈ 1:1 · 数值为连贯示例（CPU 116% ≈1.2 核 = 线程榜之和；内存 1.2G 为子进程 VmRSS）

行为约定（形态 A）

  • 悬浮钮常驻不可隐藏，不加隐藏能力（评审决定 2026-10-16）——它是电源/串口/工具栏唯一入口，完全收起态 = 只剩圆钮（帧①）
  • 状态消息 chip 整体移除（评审决定 2026-10-16，落地时改 app）——钮旁只留 HUD 读数 chip；「启动完成/已退出」这类反馈不再常显
  • 采样 1s；仅 HUD 开 + 窗口前台时跑；开关入全局偏好（同输入设置，跨 VM 手感一致）
  • 数据源 native vmStats(vmId)：读子进程 /proc（task/*/stat CPU ticks + 线程名、status VmRSS、io 读写差分出速率）
  • 不走 QMP——观测手段不吊死在被观测者上（同「四道防线」就绪判定理由）；任何 guest、任何状态可读
  • CPU 口径 100% = 1 核（top），旁标核数换算；线程名即 qemu 线程名，开发者向
  • 排除项：不显示 FPS（渲染侧接线后置）、guest 内部负载（需 guest agent）、网络速率（/proc 无 per-进程口径）、历史曲线（待形态 C）
