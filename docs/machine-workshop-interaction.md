# 机器工坊 + OS 模板库 —— 交互设计稿

> 状态：已获用户确认（2026-08-22）。本稿只界面对话/流程，不含实现。
> 数据模型/命令行前提（`VmMachine` 扩充 + `buildArgs` 参数化）见文末「实现前提」。

## 0. 目标

把「新建一台能跑起来的 VM」从"裸填扁平表单"升级为「选模板 / 走分步向导」，让
**跑异构 OS（Alpine/Android-x86/DOS/裸内核）开箱即用**，同时把隐藏的
machine/板卡/固件/直启内核等一等公民化，供开发者自查。

既有页面关系：`VmWizard` 取代 `Index.pageMap` 的 `edit` 指向；`VmEdit` 保留为高级/直改入口。

---

**交互规则**

- 点模板 → 预设参数**灌进向导**（后续可逐项改，不锁死）。
- 点「从零开始」→ 向导从默认值起（x86_64 / pc / SeaBIOS）。
- 卡片公共字段：名称 / 架构 / 一句说明 / **镜像状态**（内置✓ / 需自备）/ 一条预设亮点。
- 「无镜像」卡片灰字标注「需自备镜像」，但**不禁止选择**（先配置、后导入镜像亦可）。

## 2. 机器工坊向导（分步）

顶部**步骤指示器**（可点回任意步骤），底部**上一步 / 下一步 / 完成**，某步可折叠 1px「高级」。

```
┌─ 机器工坊 ───────────────────────────────────────────────┐
│  ① 架构   ② 板卡/固件   ③ CPU/内存   ④ 介质   ⑤ 网络   ⑥ 完成 │
├──────────────────────────────────────────────────────────┤
│  （当前步骤内容）                                         │
├──────────────────────────────────────────────────────────┤
│                    [ 上一步 ]   [ 下一步 → ]               │
└──────────────────────────────────────────────────────────┘
```

| 步骤 | 控件 | 联动规则 |
|---|---|---|
| ① 架构 | x86_64 / i386 / aarch64 三选一卡片 | 改架构重算 ②③④ 选项；不适配项回退默认 |
| ② 板卡/固件 | 按架构过滤：x86 `pc`/`q35`；aarch64 `virt`/`raspi`；固件 SeaBIOS/OVMF(UEFI) | 每卡一句强弱说明；固件与板卡绑定 |
| ③ CPU/内存 | 核数 + 内存 Slider（沿用现有） | 无 |
| ④ 介质 | 系统盘（大小/动态/固定）+ 光盘 ISO（内置Alpine/路径）+ 启动顺序 + **直启内核**(-kernel/-initrd/-append) | 直启内核勾选后盘/ISO 弱化（可选填） |
| ⑤ 网络 | 启用 / 端口转发 / 9p 共享（沿用现有） | 无 |
| ⑥ 命名+概览 | 名称 + **buildArgs 只读预览**（实时生成，开发者自查）+ [创建] | 创建才真正 `qemu-img create`（延续「取消不留孤儿」） |

**关键交互点**

1. 模板 = 预填向导，**不锁死**，最终以向导填的为准。
2. 第⑥步 `buildArgs` 实况预览（纯函数），高级用户一眼看穿。
3. 架构-板卡-固件**联动**，避免配出跑不起来的组合。
4. 编辑已有 VM = 「编辑模式」：预填现值、不改 id、多「覆盖保存」。

## 3. 待实现前置（数据模型 + 命令行）

模板/向导不能只"填个寂寞"，前提是数据模型和 buildArgs 参数化：

- `VmMachine` 扩为：`arch` / `machine('pc'|'q35'|'virt'|'raspi')` /
  `firmware('seabios'|'ovmf')` / `cpuModel(string, ''=自动)`。
- `buildArgs`：按 `machine` 传 `-machine`；aarch64 默认 `virt` + `-cpu max`；x86 默认
  `pc`（与 qemu 默认一致，不破坏现有启动）；firmware=ovmf 走 pflash 需 OVMF 文件
  （缺则回落 seabios，不阻塞）。
- schema 仍 v2：`normalizeV2` / `migrateV1` 回填默认（pc / seabios / ''），保证旧配置
  读进来行为不变。

---

## 4. 实现拆分（一项一 commit、一项一验证）

1. **机器抽象**：`VmMachine` 扩字段 + `buildArgs` 参数化（默认不变、旧配置行为不回退）。
2. **OS 模板库**：内置 Alpine / Android-x86 / DOS / 裸内核 四套参数 + 首页模板入口。
3. **向导 UI**：`VmWizard` 分步（架构→板卡/固件→CPU/内存→介质→网络→命名+概览），
   替换 `edit` 指向；`VmEdit` 留作「高级」。
